# Security Policy

## Supported versions

Security fixes are applied to the latest released version of fp-tools.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository when
available. If private reporting is unavailable, contact the repository owner
through the Oncology Lab GitHub organization without publishing exploit
details in a public issue.

Include the affected version, reproduction steps, potential impact, and any
suggested mitigation. Reports will be acknowledged as soon as practical.

Scientific correctness bugs that do not expose a security boundary may be
reported through the public issue tracker.
