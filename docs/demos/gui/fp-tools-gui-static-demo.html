Explore the fp-tools GUI

This interactive demo shows example inputs, YAML, and run history. It does not read your files or run analyses. To use your own data, install fp-tools and open fp-tools-gui.

1. Choose a commandUse the menu to explore each example.
2. Check the inputsSee which files and sample labels the command needs.
3. Review the YAMLReplace the example paths in your installed GUI.
4. View example historySee how the GUI records commands and output paths.
