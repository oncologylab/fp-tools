# Paper And Reproducibility

The manuscript, figure builders, and benchmark helpers are kept in the repository so results can be regenerated from public inputs.

## Reproduction Guide

See:

- [Reproduce the paper](reproduce-paper.md)
- [Future plans](FUTURE_PLANS.md)

## Public Data

Large public-data files are not stored directly in the source tree. The repository includes manifests, scripts, small result tables, and figure builders; larger reusable example data can be distributed through release assets or the companion data repository.

## Manuscript Assets

Selected diagrams and static figures used by the docs site are stored under `docs/assets/`.
