# GUI Config Examples

These YAML files use the repository's `test_data/` inputs. From the repository
root, preview a command before running it:

```bash
run-yaml-workflow --config examples/gui_configs/call_footprints_single.yml --dry-run
```

Remove `--dry-run` to run the analysis. You can also load a file in the GUI's
Config page. For your own analysis, copy an example and replace its input and
output paths; paths are resolved from the directory where you launch fp-tools.

The examples write outputs under:

```text
examples/gui_demo_outputs/
```
